# Waitlist Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/waitlist` route (two-column pitch + interactive form) that captures real signups into Cloudflare KV via a Worker endpoint, and wire the site's three "Get Early Access" buttons to it.

**Architecture:** Astro stays fully static. A new `src/pages/waitlist.astro` (modeled on `index.astro`) composes `Header`/`Footer` + two new components under `src/components/waitlist/`. Interactivity is a scoped vanilla-TS `<script>` island (no React). Submissions POST to `/api/waitlist`, handled by a small Worker entry placed in front of the existing static-assets Worker; it writes to a `WAITLIST` KV namespace.

**Tech Stack:** Astro 5 (static), Tailwind v4 utilities + scoped `<style>`, CSS custom-property tokens from `src/styles/global.css`, a Cloudflare Worker (`worker/index.ts`) bundled by wrangler. Package manager **bun**; wrangler is a devDependency.

## Global Constraints

- Reuse existing tokens; add exactly one new token: `--err` (`#b4452f` light / `#ee9d87` dark). No other new color literals except ones already present in the design (e.g. the card shadow `rgba(34,30,25,.5)`, matching the existing product-card shadow).
- Vanilla `<script>` islands only — no React, no `client:*`, no new runtime deps.
- Form fields (trimmed): `name`*, `email`*, `business`*, `maps_url`, `locations` (default `1`), `source` (**no default**), `consent`*. Plus hidden honeypot `company_website`. Monthly-reviews and the note textarea are dropped.
- Validation: no errors until first submit (`touched`), then live-clear. Messages verbatim: name→"Please tell us your name." email→"Enter a valid email address." business→"Please tell us your business name." consent→"Please tick this so we can email you your invite."
- Email regex (client + server, identical): `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`.
- Accessibility: real `<label for>`; errored inputs get `aria-invalid="true"` + `aria-describedby`; segmented pickers are `role="radiogroup"` with native radio inputs; consent is a real checkbox with the row as its label; success heading is `role="status"` and receives focus; ripple/dot/pop disabled under `prefers-reduced-motion`.
- Internal links plain root-relative (`/waitlist`, `/privacy`, `/`).
- Backend: Worker handles `POST /api/waitlist` only; everything else → `env.ASSETS.fetch(request)`. Honeypot non-empty → silent `{ok:true}` (no store). Re-validate required fields server-side. Normalize email `trim().toLowerCase()`. Dedupe idempotently on key `waitlist:<email>`. KV binding `WAITLIST`.
- Verification: `bun run build` clean; page/UI via `bun run dev`; endpoint via `bunx wrangler dev` (local KV). No unit-test harness exists for this static site.
- SEO: `title: Join the waitlist — ReplyOmat`; `description: Request an invite to the ReplyOmat beta. AI-drafted replies to your Google reviews, approved by you.`; indexable.

### Task 3: Worker endpoint + KV binding

Adds the Worker that handles `POST /api/waitlist` in front of the static assets, and the wrangler config for it + the KV namespace.

**Files:**
- Create: `worker/index.ts`
- Modify: `wrangler.jsonc`

**Interfaces:**
- Produces: `POST /api/waitlist` accepting JSON `{name,email,business,maps_url,locations,source,consent,company_website}` and returning `{ok:true}` (200) or `{ok:false,error}` (400). The Task 4 island consumes this contract.

- [ ] **Step 1: Create the Worker**

Create `worker/index.ts` (minimal inline types so no `@cloudflare/workers-types` dependency is needed):

```ts
/**
 * Front-of-assets Worker. Only POST /api/waitlist is handled here; every
 * other request is delegated to the static assets binding, so the Astro
 * site's routing is unchanged. Writes signups to the WAITLIST KV namespace.
 */
interface Env {
  WAITLIST: {
    get(key: string): Promise<string | null>
    put(key: string, value: string): Promise<void>
  }
  ASSETS: { fetch(request: Request): Promise<Response> }
}

const EMAIL_RE = /^[^\s@]+@[^\s@]+\.[^\s@]+$/

function json(body: unknown, status = 200): Response {
  return new Response(JSON.stringify(body), {
    status,
    headers: { "content-type": "application/json" },
  })
}

async function handleWaitlist(request: Request, env: Env): Promise<Response> {
  let body: Record<string, unknown>
  try {
    body = (await request.json()) as Record<string, unknown>
  } catch {
    return json({ ok: false, error: "Invalid request." }, 400)
  }

  const str = (v: unknown) => (typeof v === "string" ? v : "")

  // Honeypot: bots fill the hidden field. Absorb silently with a 200 so
  // they get no signal, and never touch KV.
  if (str(body.company_website).trim() !== "") {
    return json({ ok: true })
  }

  const name = str(body.name).trim()
  const email = str(body.email).trim().toLowerCase()
  const business = str(body.business).trim()
  const consent = body.consent === true

  if (!name || !business || !EMAIL_RE.test(email) || !consent) {
    return json({ ok: false, error: "Please complete the required fields." }, 400)
  }

  const record = {
    name,
    email,
    business,
    maps_url: str(body.maps_url).trim(),
    locations: str(body.locations),
    source: str(body.source),
    consent: true,
    submitted_at: new Date().toISOString(),
  }

  // Idempotent dedupe: one record per email; a repeat submit still returns
  // ok (don't leak whether they already signed up).
  const key = `waitlist:${email}`
  const existing = await env.WAITLIST.get(key)
  if (!existing) {
    await env.WAITLIST.put(key, JSON.stringify(record))
  }

  return json({ ok: true })
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url = new URL(request.url)
    if (url.pathname === "/api/waitlist" && request.method === "POST") {
      return handleWaitlist(request, env)
    }
    return env.ASSETS.fetch(request)
  },
}
```

Adds the scoped `<script>` to `WaitlistForm.astro`: touched-gated validation, submit → `/api/waitlist`, sending state, success swap with focus, and a general error affordance.

**Files:**

- [ ] **Step 1: Append the island script**

At the end of `src/components/waitlist/WaitlistForm.astro` (after the closing `</style>`), add:

```astro
<script>
  ;(function () {
    const form = document.getElementById("wl-form") as HTMLFormElement | null
    const formCard = document.getElementById("wl-form-card")
    const successCard = document.getElementById("wl-success-card")
    const submitBtn = document.getElementById("wl-submit") as HTMLButtonElement | null
    if (!form || !formCard || !successCard || !submitBtn) return

    const sendDefault = submitBtn.querySelector<HTMLElement>(".wl-send-default")
    const sendLoading = submitBtn.querySelector<HTMLElement>(".wl-send-loading")
    const generalError = document.getElementById("wl-error")

    const nameEl = document.getElementById("wl-name") as HTMLInputElement
    const emailEl = document.getElementById("wl-email") as HTMLInputElement
    const bizEl = document.getElementById("wl-business") as HTMLInputElement
    const consentEl = document.getElementById("wl-consent") as HTMLInputElement

    const EMAIL_RE = /^[^\s@]+@[^\s@]+\.[^\s@]+$/

    // Each required field: its input, its error span id, and a validity test.
    const checks = [
      { el: nameEl, errId: "err-name", ok: () => nameEl.value.trim().length > 0 },
      { el: emailEl, errId: "err-email", ok: () => EMAIL_RE.test(emailEl.value.trim()) },
      { el: bizEl, errId: "err-business", ok: () => bizEl.value.trim().length > 0 },
      { el: consentEl, errId: "err-consent", ok: () => consentEl.checked },
    ]

    let touched = false

    function applyField(c: (typeof checks)[number]) {
      const errEl = document.getElementById(c.errId)
      const valid = c.ok()
      const showErr = touched && !valid
      if (errEl) errEl.hidden = !showErr
      // The consent input is visually hidden; mark its error state without
      // the `.bad` input tint (which only makes sense on text inputs).
      if (c.el !== consentEl) c.el.classList.toggle("bad", showErr)
      if (showErr) {
        c.el.setAttribute("aria-invalid", "true")
        c.el.setAttribute("aria-describedby", c.errId)
      } else {
        c.el.removeAttribute("aria-invalid")
        c.el.removeAttribute("aria-describedby")
      }
    }

    function refresh() {
      checks.forEach(applyField)
    }

    // Live validation only after the first submit attempt.
    checks.forEach((c) => {
      const evt = c.el === consentEl ? "change" : "input"
      c.el.addEventListener(evt, () => {
        if (touched) refresh()
      })
    })

    function setSending(sending: boolean) {
      submitBtn!.disabled = sending
      if (sendDefault) sendDefault.hidden = sending
      if (sendLoading) sendLoading.hidden = !sending
    }

    async function send() {
      if (generalError) generalError.hidden = true
      setSending(true)
      const payload = {
        name: nameEl.value.trim(),
        email: emailEl.value.trim(),
        business: bizEl.value.trim(),
        maps_url: (document.getElementById("wl-maps") as HTMLInputElement).value.trim(),
        locations:
          (form!.querySelector('input[name="locations"]:checked') as HTMLInputElement | null)?.value || "",
        source: (document.getElementById("wl-source") as HTMLSelectElement).value,
        consent: consentEl.checked,
        company_website:
          (form!.querySelector('input[name="company_website"]') as HTMLInputElement | null)?.value || "",
      }
      try {
        const res = await fetch("/api/waitlist", {
          method: "POST",
          headers: { "content-type": "application/json" },
          body: JSON.stringify(payload),
        })
        const data = (await res.json().catch(() => ({}))) as { ok?: boolean }
        if (!res.ok || !data.ok) throw new Error("failed")
        showSuccess(payload.name, payload.email)
      } catch {
        setSending(false)
        if (generalError) generalError.hidden = false
      }
    }

    function showSuccess(fullName: string, email: string) {
      const first = fullName.trim().split(/\s+/)[0] || "there"
      const nameSpan = document.getElementById("wl-done-name")
      const emailSpan = document.getElementById("wl-done-email")
      if (nameSpan) nameSpan.textContent = first
      if (emailSpan) emailSpan.textContent = email
      formCard!.hidden = true
      successCard!.hidden = false
      const heading = document.getElementById("wl-done-heading")
      if (heading) heading.focus()
    }

    form.addEventListener("submit", (e) => {
      e.preventDefault()
      touched = true
      refresh()
      const firstInvalid = checks.find((c) => !c.ok())
      if (firstInvalid) {
        firstInvalid.el.focus()
        return
      }
      send()
    })
  })()
</script>
```
